本地化指南

EasySub 默认跟随系统应用语言，目前支持简体中文与 English。应用名称 EasySub 在所有语言中保持不变。

修改现有翻译

在 Xcode 中打开 Sources/EasySubApp/Localizable.xcstrings，编辑对应语言列；也可以直接编辑这个 JSON 文件。英文为源语言，请不要通过修改 key 来调整译文。

  • 保留 %@、%d、%lld 等格式占位符的类型与数量。
  • 需要调整顺序时使用位置占位符，例如 %1$lld。
  • 新增界面文案使用 SwiftUI 本地化字符串字面量或 LocalizedStringKey；非 View 文案使用 String(localized:)。
  • 文件名、字幕标题、路径和服务返回的原始内容不属于应用翻译。

增加语言

  1. 在 String Catalog 中添加语言并完成翻译，保留英文作为回退。
  2. 在 Sources/EasySubCore/ApplicationLanguage.swift 中增加语言代码。
  3. 在 SettingsView 的语言选择器中添加选项，并用该语言自己的写法显示语言名称。
  4. 在 Scripts/generate_project.py 的 knownRegions 中加入语言代码。
  5. 运行 python3 Scripts/generate_project.py，提交生成的工程变化。
  6. 构建并检查主窗口、设置、字幕选择、空状态、错误提示与完成通知。

验证重点

  • 验证默认跟随系统、手动选择、重启后保持选择，以及恢复跟随系统。
  • 检查长译文是否截断、占位符是否正确、EasySub 品牌名是否保持不变。
  • 切换语言前应完成下载；当前队列不会跨重启保存。

语言选择通过应用域的 AppleLanguages 保存。恢复跟随系统时只移除应用自己的覆盖，不会修改全局系统语言。
