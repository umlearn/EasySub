01 / 使用方式

从视频到字幕，三步就够。

01

拖入视频

添加单个视频或整个文件夹，自动扫描并去重。

02

自动匹配

并行搜索多个来源，按片名、年份、季集和语言排序。

03

保存字幕

选择 ASS、SRT 或两者，字幕自动保存到视频旁边。

常见问题

未签名版本如何在 macOS 上打开？

在 Finder 中右键点击 EasySub，选择“打开”。如果仍被阻止，请前往“系统设置 → 隐私与安全性”，确认打开该应用。

EasySub 会上传我的视频吗？

不会。视频始终保留在本地。部分来源会使用整理后的文件名，或在本地读取少量片段计算指纹。

下载字幕需要账户或 Token 吗？

取决于来源。迅雷无需 Token；ASSRT 需要个人 Token；OpenSubtitles 需要 API Key。你可以在设置中自由组合。

支持哪些格式？

字幕支持 ASS 与 SRT；视频支持 MKV、MOV、MP4、M4V、RMVB、AVI、MPEG、MPG、TS、M2TS 和 WebM。
